# Классификация функциональных стилей русского текста

Автоматическая классификация фрагментов русскоязычного текста по **пяти функциональным стилям**. Реализован полный цикл — от сбора и очистки корпуса до обучения нескольких моделей и веб-приложения.

## Задача

По входному фрагменту текста определить, к какому функциональному стилю он относится. 

| ID | Стиль | Источники |
|----|--------|-------------------|
| 0 | Научный | Научные тексты |
| 1 | Официально-деловой | Российские федеральные законы |
| 2 | Публицистический | Материалы с lenta.ru |
| 3 | Разговорный | Посты из VK |
| 4 | Художественный | Русская класическая литература |

Для каждого стиля в корпусе собрано **~2000 фрагментов**; после объединения и разбивки получается около **10 000** размеченных примеров.

## Возможности

- Сбор и предобработка корпуса под каждый стиль (очистка PDF-артефактов, лемматизация, стоп-слова)
- Обучение **классических моделей** на TF-IDF: Naive Bayes, Linear SVM, Random Forest
- **Fine-tuning RuBERT** (`DeepPavlov/rubert-base-cased`) для максимального качества
- **Flask-приложение** с выбором модели и визуализацией вероятностей по всем классам
- **Консольная демонстрация** (`chat_demo.py`) для быстрой проверки без браузера
- Сохранение метрик и графиков сравнения моделей

## Результаты 

| Модель | Val F1 (macro) | Test F1 (macro) | Test accuracy |
|--------|----------------|-----------------|---------------|
| Naive Bayes | 0.952 | 0.952 | 0.952 |
| SVM (LinearSVC) | 0.964 | **0.972** | 0.972 |
| Random Forest | 0.935 | 0.931 | 0.931 |
| **RuBERT** | 0.989 | **0.990** | 0.990 |

Лучший результат даёт fine-tuned RuBERT; среди классических моделей лидирует SVM.

## Пайплайн данных

### 1. Сбор фрагментов

Скрипты `build_*.py` читают сырые `.txt` из `cmd/draft/`, прогоняют через `dataset_chunking.py` и сохраняют CSV с полями `text`, `label`, `style`, `style_ru`.

Параметры нарезки (`dataset_chunking.py`):

- минимальная длина фрагмента — **800** символов;
- целевая — **~1500**;
- максимальная — **3000**;
- исправление битой кодировки (mojibake), склейка переносов слов, разбиение по предложениям и абзацам.

### 2. Предобработка (`*_cleaner.py`)

Для каждого стиля — единый конвейер:

1. Удаление URL, артефактов разметки, лишних символов
2. Приведение к нижнему регистру, нормализация пробелов
3. Токенизация, фильтрация стоп-слов (русский список)
4. Лемматизация через **pymorphy3**
5. Отбор фрагментов с минимум **5** токенов после очистки

Результат сохраняется в `cmd/datasets/preprocessed/*_preprocessed.csv` (колонка `text_ready`).

### 3. Финальный датасет (`final_dataset.py`)

Объединяет все 5 предобработанных CSV и делает **стратифицированную** разбивку:

| Выборка | Доля |
|---------|------|
| Train | 70% |
| Val | 15% |
| Test | 15% |

Доли классов сохраняются во всех сплитах. Файлы: `corpus.csv`, `train.csv`, `val.csv`, `test.csv`.

## Обучение моделей

### Классические модели (`train_classical.py`)

- Признаки: **TF-IDF** (uni- и биграммы, до 50 000 признаков, `sublinear_tf=True`)
- Обучение только на `train`; подбор гиперпараметров — **GridSearchCV** (5-fold, метрика `f1_macro`)
- Сохраняются: `tfidf_vectorizer.pkl`, `naive_bayes.pkl`, `svm.pkl`, `random_forest.pkl`, `classical_results.csv`

| Модель | Подбираемые параметры |
|--------|------------------------|
| Naive Bayes | `alpha` |
| LinearSVC | `C`, `class_weight='balanced'` |
| Random Forest | `n_estimators`, `max_depth`, `min_samples_leaf` |

Классические модели работают с колонкой **`text_ready`** (лемматизированный текст).

### RuBERT (`train_bert.py`)

| Параметр | Значение |
|----------|----------|
| Базовая модель | `DeepPavlov/rubert-base-cased` |
| Max length | 256 |
| Batch size | 16 |
| Эпохи | 4 |
| Learning rate | 2e-5 |
| Оптимизатор | AdamW + linear warmup (10% шагов) |
| Сохранение | лучший чекпоинт по **Val F1 macro** → `models/rubert_best/` |

## Веб-приложение

Интерфейс в стиле чата: пользователь вводит текст, выбирает модель в боковой панели, получает предсказанный стиль и распределение вероятностей по всем классам.

**Эндпоинты:**

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/` | Главная страница |
| POST | `/classify` | Классификация текста (JSON) |

**Пример запроса:**

```json
{
  "text": "В ходе исследования была проведена статистическая обработка полученных данных.",
  "model": "rubert"
}
```

**Допустимые значения `model`:** `naive_bayes`, `svm`, `random_forest`, `rubert`.

**Пример ответа:**

```json
{
  "predicted_id": 0,
  "predicted_name": "Научный",
  "predicted_color": "#534AB7",
  "confidence": 87.3,
  "all_probs": [
    {"id": 0, "name": "Научный", "color": "#534AB7", "prob": 87.3},
    ...
  ]
}
```

Для классических моделей перед предсказанием применяется упрощённая предобработка (нижний регистр, стоп-слова, токены ≥ 3 символов). RuBERT получает исходный текст с токенизацией на стороне transformers.

## Установка и запуск

### 1. Клонирование и окружение

```bash
git clone <url-репозитория>
cd classification_of_text_styles
python -m venv .venv
source .venv/bin/activate   
pip install -r requirements.txt
```

### 2. Модели

Файлы моделей **не входят в git** (см. `.gitignore`: `*.pkl`, `cmd/models/rubert_best/`). Для работы приложения нужны:

- `cmd/models/tfidf_vectorizer.pkl`
- `cmd/models/naive_bayes.pkl`, `svm.pkl`, `random_forest.pkl`
- `cmd/models/rubert_best/` (для RuBERT)



### 3. Запуск веб-приложения

```bash
cd cmd
python app.py
```

Откройте в браузере: **http://127.0.0.1:5000**

Минимальная длина входного текста — **3 слова**.

### 4. Консольная демонстрация

```bash
cd cmd
python chat_demo.py
```

Интерактивный ввод текста и выбор модели в терминале.


## Примечания

- Обучение RuBERT требует заметных ресурсов; на CPU inference работает, но медленнее.
- Датасет `cmd/draft/` объёмный и исключён из репозитория — для воспроизведения сборки нужны локальные исходные тексты.
